## Behaviour notes
- parseBoard never throws; returns Vietnamese errors. Validates JSON, version (newer rejected), name, mode, node kinds, param types (merged with defaults, unknown params dropped), unique ids, wires via canConnect (messages from engine CONNECT_FAIL_TEXT).
- Parsed boards have full params, so serialize->parse is stable.
- Autosave: key `xuong-noi:autosave`, 1 s debounce, corrupt -> copied to `xuong-noi:autosave-backup`, main key removed, null returned.
- Extra exports beyond BoardIo (index.ts): `flushAutosave()` (call on pagehide/beforeunload), `takeAutosaveProblem()` (returns+clears Vietnamese message for corrupt autosave / write failure, for the UI to show).
- downloadBoard filename sanitized (`safeFileName`), pickBoardFile handles cancel event, 5 MB cap.
- listSamples returns fresh parsed copies: side-stars "Nhặt sao (nhảy 2D)", top-collect "Thu thập (nhìn từ trên)", 3d-hop "Nhảy cóc 3D".
- Node ids in samples are `<tag>-<n>` (e.g. character-1, star-1, counter-1).
- Samples were generated by a throwaway script (scratchpad), JSON is committed as the source of truth.
- Sample design: stars/items chained with `or` nodes into counter.up (one wire per input); object<->touch loops use the engine's back-edge handling.
