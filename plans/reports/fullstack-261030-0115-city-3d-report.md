## Rules and controls
- W A S D drive the "Xe tải nhỏ" (auto-boarded, braked until the start button). Camera "Chéo từ trên", zoom 0.5. **Space** drops 1 item (to make room; added because leftovers would clog the 4-slot truck).
- Bay (yellow pad): truck touching it loads that bay's type, capacity 4. Order text "Đơn: <Khu> – Nhà <n> cần 3 <loại>", arrow with distance, "Giao ở đây!" label. Inside the active house pad only the needed type unloads, one item per 0.15 s; partial deliveries count (progress shown). 3 items complete the order, +40 money, new order, 90 s clock.
- Late order: -1 tim + new order. 6 orders win, 0 tim lose.
- Crash with a bot car: truck stalled 5 s (latch + timer), cargo drops 1 any-type item, camera shakes, message "Va chạm! Mất 1 món hàng, chờ 5 giây" (short text if the truck was empty).
- HUD: Đã giao, Tim, Tiền, progress, time bar, goods per type + total, help lines bottom-left.

## Deviations (honest notes)
- Red light is implemented as "car touches its red stop-line block" (Cảm biến chạm) not a zone: a zone cannot tell which car is inside, so every car on the loop would stop. Same effect: route "Dừng" while the light is red/yellow.
- Deliver pads and bay pads use touch(truck, pad) instead of zones for the same reason (bot cars would trigger a zone).
- Order text is static per order; "còn T giây" is shown by the time bar/number (no dynamic text node).
- Long solid boxes beside a lane make route cars over-cautious (axis-aligned probe) and a halted car never steers, so the edge fence is in 5-unit pieces 8+ units from lanes.
